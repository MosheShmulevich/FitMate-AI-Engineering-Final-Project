# FitMate 💪

FitMate is an AI-powered personal fitness coach designed primarily for beginner and intermediate gym trainees.

The system combines a LangGraph AI Agent, professional fitness knowledge, Advanced RAG, specialized tools, a Workout Planning Skill, short-term conversation memory, long-term user memory, automated evaluations, and a Hebrew Streamlit user interface.

---

## Problem

Beginner and intermediate trainees are often exposed to conflicting, misleading, or unreliable fitness information.

As a result, they may struggle to:

- Build an appropriate workout program
- Understand professional training principles
- Track their progress
- Adjust their training over time
- Distinguish between professional information and unsupported advice

---

## Solution

FitMate acts as a personal AI fitness coach.

The system can:

- Generate personalized workout programs
- Answer professional fitness questions
- Retrieve information from a professional knowledge base
- Manage trainee profiles
- Track workout progress
- Calculate training volume
- Save workout programs
- Remember user data between sessions
- Adapt recommendations according to user information
- Avoid unsupported professional answers when the knowledge base is insufficient

---

## AI Agent

FitMate uses a LangGraph-based AI Agent.

The Agent decides when to:

- Answer directly
- Search the professional knowledge base
- Use a Tool
- Retrieve trainee profile information
- Retrieve workout history
- Save workout progress
- Apply the Workout Planning Skill

This allows FitMate to perform actions and make decisions instead of functioning as a simple LLM chatbot.

### Basic RAG

The baseline implementation is located in:

`rag.py`

It includes:

- OpenAI Embeddings
- Pinecone Vector Database
- Semantic Vector Search
- Chunking
- Metadata storage
- Source tracking
- Page tracking
- Chunk tracking

The Basic RAG implementation is preserved as a baseline for comparison.

### Advanced RAG

The improved retrieval pipeline is located in:

`advanced_rag.py`

It includes:

- Semantic Vector Search
- BM25 Keyword Search
- Hybrid Search
- Reciprocal Rank Fusion (RRF)
- Context-Aware LLM Reranking

The Advanced RAG pipeline combines semantic and keyword retrieval, fuses both rankings using RRF, and then reranks the strongest candidates according to their usefulness for answering the user's exact question.

The pipeline was designed to:

- Improve retrieval quality
- Prioritize useful professional content
- Reduce weak title-only results
- Reduce irrelevant discussion material
- Prefer practical recommendations and professional explanations

### RAG Comparison Demo

A dedicated Streamlit comparison interface is available in:

`rag_comparison_demo.py`

It provides a side-by-side comparison between:

- Basic RAG
- Advanced RAG

The comparison demonstrates how Hybrid Search, RRF, and Context-Aware Reranking improve retrieval quality compared with semantic vector search alone.

## Tools

The FitMate Agent currently includes the following tools.

### `calculate_training_volume`

Calculates workout volume using:

```text
sets × repetitions × weight
```

### `get_user_profile_tool`

Retrieves trainee profile information from SQLite.

### `save_user_progress_tool`

Stores workout performance in the database.

The current date is generated automatically by the system instead of being generated by the language model.

### `get_user_progress_tool`

Retrieves previous workout records for the trainee.

### `search_fitness_knowledge`

Searches the professional fitness knowledge base using the Advanced RAG pipeline.

## Workout Planning Skill

FitMate includes a dedicated Workout Planning Skill:

`skills/workout_planning/SKILL.md`

Before creating a workout program, the system considers:

- Training goal
- Experience level
- Training days per week
- Available time per session
- Available equipment
- Limitations and preferences

If important information is missing, FitMate should request it instead of guessing.

If the information already exists in the trainee profile, the Agent can retrieve it automatically.

---

## Memory

FitMate uses both short-term and long-term memory.

### Short-Term Memory

LangGraph maintains conversation context during the current conversation.

### Long-Term Memory

SQLite stores persistent user information, including:

- Trainee profile
- Training goal
- Experience level
- Training days per week
- Session duration
- Available equipment
- Workout progress
- Saved workout programs

This information remains available even after the application is closed and restarted.

---

## Grounding and Hallucination Prevention

For professional fitness questions, FitMate uses its professional knowledge base as the authoritative source.

If the retrieved knowledge does not sufficiently support the requested information, FitMate is instructed not to fill the gap using general model knowledge.

For example, if a user asks for an exact personalized creatine dosage and the current knowledge base does not contain sufficient information to determine an exact dosage for that user, FitMate states that the available information is insufficient instead of inventing a recommendation.

## Prompt Injection Protection

FitMate includes prompt-level protection against attempts to:

- Override the Agent role
- Reveal the System Prompt
- Reveal hidden instructions
- Disable safety rules
- Disable grounding rules
- Ignore Tools
- Ignore the professional knowledge base

Prompt injection resistance is also included in the automated evaluation suite.

## Personalized Workout Plans

FitMate can generate workout programs according to the trainee profile.

The program considers:

- Goal
- Experience level
- Weekly training frequency
- Session duration
- Available equipment
- Limitations and preferences
- Professional information retrieved from the knowledge base

Generated workout programs are saved in SQLite and remain available after restarting the application.

## Progress Tracking

FitMate allows workout performance to be stored and retrieved.

Each progress record may contain:

- Date
- Exercise
- Sets
- Repetitions
- Weight
- Notes

The application also calculates and displays training volume.

## Installation

Create a virtual environment:

```powershell
python -m venv .venv
```

Activate the virtual environment:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install the required packages:

```powershell
pip install -r requirements.txt
```
